# COA Arena: Memory World

An interactive Computer Organization and Architecture learning game focused on memory organization.

- **Live website:** https://coa-memory-arena.higgsfield.app/
- **GitHub repository:** https://github.com/bhagyasribolisetty2-dotcom/coa-memory-arena

## See the website code

The repository includes the complete readable source and configuration bundle: **582 files**.

1. Download [coa-memory-arena-source-code.tar.xz](./coa-memory-arena-source-code.tar.xz) from this repository.
2. Extract it with 7-Zip (or another `.tar.xz` extractor).
3. Open the extracted `app/src` folder to browse the website source.

The full media bundle, including the large video, audio, image, and font assets, is available here:

[Download the complete website bundle](<https://d2ol7oe51mr4n9.cloudfront.net/user_3L8XCLiAp4WJddLWtk0N0FpUyfd/4125a279-a456-4441-9cca-a1b1d7d2f7a2.zip>)

## Run locally

The app uses Bun. From the extracted `app` folder:

```sh
bun install
bun run dev
```
